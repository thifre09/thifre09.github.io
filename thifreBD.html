Introdução

Bem-vindo ao ThifreBD, um sistema de gerenciamento de banco de dados relacional (SGBD) que permite criar, gerenciar e consultar bancos de dados de forma intuitiva e eficiente. Com o ThifreBD, você pode criar tabelas, inserir dados, realizar consultas SQL.

Há 2 formas de usar o ThifreBD: o dashboard e o terminal.

Dashboard (Interface Gráfica)

A interface gráfica permite que você crie e gerencie bancos de dados de forma visual e intuitiva.

  • Ideal para quem prefere interação visual
  • Visualização intuitiva dos dados
  • Sem necessidade de escrever código SQL

Terminal (SQL)

O terminal permite que você execute comandos SQL diretamente para interagir com o banco de dados.

  • Ideal para quem prefere trabalhar com comandos SQL
  • Mais rápido para usuários experientes
  • Consultas e manipulação de dados mais avançadas

Importante

Nas 2 formas, os dados são os mesmos. Então alterar algo no dashboard também afetará os dados no terminal, e vice-versa. Por isso, é possível trabalhar com ambos os métodos simultaneamente.

Como funciona

Database

Contém um conjunto de schemas

Schema

Contém um conjunto de tabelas

Tabela

Contém um conjunto de colunas e linhas

Coluna

Representa uma característica ou atributo da tabela

Linha

Representa um registro ou instância da tabela

Dashboard

O dashboard permite usar o sistema através de uma interface gráfica intuitiva, sem que sejam necessários conhecimentos de SQL

Lado esquerdo

Na esquerda, é possível criar uma nova database e uma tabela.

Para criar uma nova database, basta clicar no botão de + do lado da palavra "Database".

Para criar uma nova tabela, selecione uma database existente e clique no botão de + do lado da palavra "Tabela". Tentar criar tabela sem selecionar uma database não é permitido.

Para editar uma database existente, clique no botão de edição ao lado da palavra "Database".

Para mudar a database ativa, clique no dropdown de databases, que possui o nome da database selecionada. Caso nenhuma database esteja selecionada, o dropdown mostrará "Selecione uma database". Ao mudar a database, todas as suas tabelas serão exibidas na parte de tabelas.

Clicar no nome de uma tabela irá selecioná-la e mostrar suas informações na direita.

Lado direito

Na topo esquerdo, é mostrado o nome da tabela atual, o número de linhas e o número de colunas.

No topo direito, há 3 botões: um para adicionar uma nova linha, outro para editar a tabela e um terceiro para fazer uma pesquisa com base na tabela.

Na parte inferior, é possível visualizar o conteúdo da tabela selecionada. A primeira linha mostra os nomes das colunas e suas características (tipo, chave primária, etc.).

Ao clicar em "editar tabela", o seguinte menu será exibido:

O primeiro botão permite mudar o nome da tabela, basta alterar o nome, e clicar em "Confirmar alterações".

O segundo botão permite modificar as colunas existentes da tabela. O terceiro botão permite adicionar novas colunas. E o quarto botão permite excluir a tabela.

Tipos de dados

Os tipos de dados são utilizados para definir o tipo de valor que pode ser armazenado em uma coluna de uma tabela. Cada tipo de dado tem suas características e limitações específicas.

Tipos de dados suportados

Tipo de dado Descrição Exemplo

Text

Armazena texto. "Olá, mundo!", "batata"

Integer

Armazena números inteiros. 42, -5

Float

Armazena números decimais. 3.14, -2.5

Boolean

Armazena valores lógicos. true, false

Date

Armazena datas. "2023-10-01", "1990-05-15"

Time

Armazena horas. "14:30:00", "09:15:30"

Enum

Armazena valores pré-definidos. "vermelho", "azul"

Varchar

Armazena strings com um tamanho máximo definido pelo usuário. "Olá, mundo!", "batata"

Restrições

Comandos SQL

Esta seção apresenta os comandos SQL atualmente suportados pelo SGBD.

USE

Seleciona uma database ou schema.

USE DATABASE

Sintaxe

Comando Descrição
USE database_name; Seleciona uma database como a database atual.

Exemplo

USE empresa;

Após executar o comando, todas as operações serão realizadas na database selecionada.

USE SCHEMA

Sintaxe

Comando Descrição
USE schema_name; Seleciona um schema como o schema atual.

Exemplo

USE empresa;

Após executar o comando, todas as operações serão realizadas no schema selecionado.

CREATE

O comando CREATE é utilizado para criar novos objetos no banco de dados.

CREATE DATABASE

Sintaxe Descrição
CREATE DATABASE database_name; Cria uma nova database.

Exemplo

CREATE DATABASE empresa;

CREATE SCHEMA

Sintaxe Descrição
CREATE SCHEMA schema_name; Cria um novo schema na database atual.

Exemplo

CREATE SCHEMA vendas;

CREATE TABLE

Sintaxe Descrição
CREATE TABLE table_name (...); Cria uma tabela no schema atual.
CREATE TABLE schema_name.table_name (...); Cria uma tabela em um schema específico.

Exemplo

CREATE TABLE clientes (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    email TEXT,
    ativo BOOLEAN
);

Cada coluna deve possuir um nome e um tipo de dado. Também é possível utilizar restrições como PRIMARY KEY, NOT NULL, UNIQUE, AUTO_INCREMENT e FOREIGN KEY.

INSERT

O comando INSERT é utilizado para adicionar novos registros a uma tabela.

Sintaxe Descrição
INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...); Insere um novo registro na tabela com as colunas especificadas.
INSERT INTO schema_name.table_name VALUES (value1, value2, ...); Insere um novo registro na tabela no schema especificado e em todas as colunas.

Exemplo

INSERT INTO clientes (nome, email) VALUES ('João', 'joao@example.com');

ALTER

O comnado ALTER é utilizado para modificar a estrutura de objetos existentes no banco de dados.

ALTER DATABASE

Sintaxe Descrição
ALTER DATABASE database_name RENAME TO new_database_name; Renomeia uma database.

Exemplo

ALTER DATABASE empresa RENAME TO nova_empresa;

ALTER SCHEMA

Sintaxe Descrição
ALTER SCHEMA schema_name RENAME TO new_schema_name; Renomeia um schema.

Exemplo

ALTER SCHEMA public RENAME TO new_public;

ALTER TABLE

Sintaxe Descrição
ALTER TABLE table_name RENAME TO new_table_name; Renomeia uma tabela.
ALTER TABLE table_name SET SCHEMA schema_name; Move uma tabela para um schema específico.
ALTER TABLE table_name ADD COLUMN column_name type; Adiciona uma nova coluna a uma tabela.
ALTER TABLE table_name DROP COLUMN column_name; Remove uma coluna de uma tabela.
ALTER TABLE table_name RENAME COLUMN column_name TO new_column_name; Renomeia uma coluna de uma tabela.

Exemplo

ALTER TABLE usuarios RENAME TO new_usuarios;
ALTER TABLE usuarios SET SCHEMA vendas;
ALTER TABLE usuarios ADD COLUMN data_criacao DATE;
ALTER TABLE usuarios DROP COLUMN ativo;
ALTER TABLE usuarios RENAME COLUMN data_criacao TO data_cadastro;

ALTER TABLE ... ALTER COLUMN

Sintaxe Descrição
ALTER TABLE table_name ALTER COLUMN column_name TYPE tipo; Altera o tipo de dado de uma coluna.
ALTER TABLE table_name ALTER COLUMN column_name SET restricao; Adiciona uma restrição a uma coluna.
ALTER TABLE table_name ALTER COLUMN column_name DROP restricao; Remove uma restrição de uma coluna.

Exemplo

ALTER TABLE usuarios ALTER COLUMN idade TYPE integer;
ALTER TABLE usuarios ALTER COLUMN ativo SET NOT NULL;
ALTER TABLE usuarios ALTER COLUMN ativo DROP DEFAULT;
